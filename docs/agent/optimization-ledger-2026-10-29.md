# 质量与剩余业务优化清单

本清单对应用户要求的八类优化。`complete` 覆盖登记是接口场景证据，不是所有视觉效果达标证明。

| 优先项 | 本轮实现/验证 | 尚需验证 |
| --- | --- | --- |
| 标注定位 | 画面短语与讲稿引用分开；OCR 阅读顺序排序；未知字形阻止确认构建；文字纠正只失效引用它的活动标注 | 多版式真实 OCR 精度分布、倾斜小字与密集文字 |
| 标注视觉 | 新 AI 建议采样目标底色，黄底/深底改对比下划线；荧光笔计入刷头半径和邻词留白；人工样式不重写 | 更多复杂纹理、彩色字体和跨行目标的视觉抽查 |
| 样片纪律 | 已从隔离样片显式移除固定坐标测试圈；新增只读 audit_annotation_quality.py 与动画边界抽样时刻；QA 清单更新为八步/双画布 | 全段主观听音、长片逐页复核 |
| 语音同步 | 已有真实 Qwen 55 字对齐证据，重复词/数字/标点/弱置信等回归保留；新几何快照使旧构建不能冒充新结果 | 多供应商快慢语速和长音频真实演练 |
| 图片文字 | 审查脚本定位未知 OCR 字形，编辑时纠正后重新确认；若源图本身错字，应通过既有单页候选生成→核对→应用修正，不用 OCR 纠正掩盖原图 | 自动判定源图语义错字不能由 OCR 占位字符检测代替；批量局部重生成尚无新增实现 |
| 供应商与恢复 | 既有默认 codex2api 明确 403 停止，隔离副本 ToAPIs 续跑已验证；创建覆盖项缺配置包时拒绝；任务沿精确 operation 查询，不盲目换键 | 用户默认供应商仍未改；长期订阅状态无法从静态配置证明 |
| 模板复用 | 新增跨项目风格/参考图快照 roundtrip；修复全局模板参考能力指向及应用参数；归档模板不能用于新应用，既有快照保留 | 风格反向分析、长课程风格一致性与真实模板生成 |
| 剩余验收 | 通过独立场景升级有证据的覆盖项；项目 CRUD/画布/模式/账号隔离/删除 CAS 新增复合场景 | 未验收条目仍维持 partial；数字人无 9001/8188 服务，已向用户询问服务/模型路径，不能用 mock 冒充生产验收 |
