# 2026-10-30 仓库更新说明

本次同步目标为 `origin/main`，包含从 `c492d91` 到 `96e3f2e` 的 10 个开发与验收提交，以及本说明的文档提交。

## 功能与修复

- 自动标注：补齐 OCR、AI 重点规划、字级音频对齐、构建、预览和确认链路；改善倾斜文字定位、跨卡片拆分、底色对比度，并提示低置信度与小字复核。
- 图片：支持候选图框选区域应用和批量修复，双哈希校验防止误覆盖，区域外像素保持不变。生成内容越过字幕安全区时，整体按比例缩入安全区，避免擦白截断正文。
- 项目状态：补充同值保存、单页失效、素材复用与失败恢复场景，保留无关页面及已确认音频。
- 风格与素材：参考图批量失败保留旧素材，元数据发布失败回滚，修复独立文件名下载路径；完善模板与声音参考素材的安全替换。
- 数字人：统一网页与 Agent 的整段生成入口，完整音频导出绑定来源快照；记录确切引擎任务 ID，超时与重启后续查原任务，验证媒体后才发布结果。
- 稳定性：连接检测受共享网关治理，异步图片检测续查原任务；补齐敏感配置导出确认、媒体探测超时和契约数值校验。

## Agent 接入变化

Agent API 升至 **3.0.0**，URL 命名空间仍为 `/api/agent/v1`。

`digital_human.generate` 改为提交一个真实整段任务，返回 `job_id/status` 并传播实际失败；不再返回原来的逐页 `results` 包装。调用方须刷新发现文档和精确能力 revision。数字人新增 `waiting_external` 状态，应继续查询原 job，不能因客户端超时重新提交。

`image.candidate.apply` 支持 `payload.regions`；局部应用必须携带原图及候选图 SHA-256。项目创建补齐目标时长、暂停阶段和风格模板字段。详见 [当前契约](current-contract-guide.md)。
