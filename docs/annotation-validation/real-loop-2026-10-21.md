## 已实际通过的链路

每种画布分别新建一个单页白底位图项目，分别调用当前配置的 MiniMax 服务生成音频，没有复用横屏音频冒充竖屏新请求。生产 Reveal 构建完成后，依次执行：

1. 正式 TTS 合成和音频确认。
2. 正式 PATCH 新增人工区域，明确指定音频时间 1.0 秒起笔、0.6 秒完成围画；该时间是工程验收输入，并非听音标注或自动定位结果。
3. 启用项目勾画，提交异步预览任务，并按其 `build_id` 确认。
4. 正式 Step 8 渲染、视频列表和下载接口；逐字节核对下载文件 SHA-256。
5. 正式单页预览导出接口，传入项目字幕设置，并实际下载预览 MP4。
6. 核对预览和成片的构建标识、事件时间、透明笔迹 PNG 哈希、视频元数据及持久化任务/作品记录。

| 画布 | 正式成片 | 预览/成片笔迹资产 | 成片目标 ROI 橙色像素：起笔前 → 中途 → 完成 |
| --- | --- | --- | --- |
| 1920×1080 | 4.733 秒 | 18/18 PNG 哈希相同，build_id/时间一致 | 0 → 1581 → 2944 |
| 1080×1920 | 4.100 秒 | 18/18 PNG 哈希相同，build_id/时间一致 | 0 → 1596 → 2924 |

抽样帧均为 29、39、49 帧，即 0.9667、1.3、1.6333 秒。两个导出预览的对应 ROI 均为 0 → 1432 → 2659。不同视频编码造成像素计数差异，本报告不宣称预览视频与成片逐像素相同。横竖屏完成帧均已实际查看，围画包围目标，第二行正文和字幕未被笔迹覆盖。

两个正式视频均为 H.264、30fps、yuv420p、BT.709，包含 AAC 音轨。视频和 `.mp4.render.json` 元数据均存在，流水线版本为 `exact_rle_mask_with_manual_corrections_v6`。两个持久化渲染任务均为 `succeeded / completed / 100 / error=NULL`；作品表注册了 2 个正式视频和 2 个勾画预览视频。

## 验收证据

目录：`outputs/annotation-loop-20261021/`（运行时产物，不提交）。

- `result.json`：最终机器可读结果、预检、API 结果、时间轴、抽帧统计、任务及作品记录。
- `preflight.json`：只含凭据是否存在，不含值。
- `landscape-final.mp4`、`portrait-final.mp4`：正式成片副本。
- `landscape-preview.mp4`、`portrait-preview.mp4`：正式接口导出的预览。
- `*-final-{before,middle,complete}.png`、`*-preview-{before,middle,complete}.png`：12 张关键帧。
- `landscape-preview.json`、`portrait-preview.json`：准备预览的完整返回值。
- `validate_loop.py`、`verify_media.py`：本轮隔离验收脚本；初始化脚本拒绝复用既有项目目录。

首次验收脚本漏接正式渲染返回的 `status=success`，曾将已经成功生成的视频判失败；媒体核查脚本也曾按错误扩展名查找 sidecar。两处均只修正验收脚本，重新查询/下载真实结果，未为此重复合成音频或渲染正式成片。初始结果保存在 `initial-harness-result.json`，以最终 `result.json` 和持久化任务记录为准。

Remotion TypeScript `tsc --noEmit` 通过，`git diff --check` 通过。本轮未修改生产实现，未重复运行此前全量回归，也不把此前全量通过数计作本轮结果。
