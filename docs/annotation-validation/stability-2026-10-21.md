# 勾画稳定性与体验改进（2026-10-21）

> 后续基线校正：原 AI Mask 确定性失败为耗时字段比较误报，16 处 lint 问题已清理；标准 full 入口现已通过，全量 pytest 为 1636 passed、1 skipped。详见 [基线校正记录](../validation-baseline-2026-10-21.md)。本文下方保留勾画改进阶段的原始验证结果。

代码基线：`a0566a8`。本轮在既有本地工作上继续修改；此前工作和同步前 stash 均保留。以下为本地实现与隔离测试记录，不代表正式服务已部署或真实供应商验收完成。

## 已实现

| 范围 | 行为与验收点 |
| --- | --- |
| 撤销与保存 | 未发送的删除可直接撤回，保留原 ID 和确认状态；删除已经发送时使用可追踪的补偿新增，成功后同步历史记录、待保存操作和选中 ID；服务端旧响应上叠加请求期间的新编辑，不再闪回旧值 |
| 草稿恢复 | 未关联讲稿的文字条目仍为本地草稿，不发送非法请求；切页和切项目时暂存，回页恢复；失败和冲突操作也按项目/页面保留；浏览器关闭提示覆盖失败、冲突、在途保存、属性编辑、未关联和其他页暂存草稿 |
| OCR 重试 | 只重试适配器明确标记 retryable 的错误，最多 3 次，等待 1/2 秒；等待可被取消；认证等不可重试错误直接失败；不改变供应商请求或识别内容 |
| AI 任务 | 发布前再次检查取消；零新增建议不重写页面、不增加 revision，前端也不启动无必要的后续音频定位 |
| 任务界面 | 使用现有取消 API；收到取消请求后显示“正在取消”，以服务端终态为准；显示已用时，不再把长时间不变的阶段数字作为实时百分比；网络失败保留任务并退避重连，旧轮询响应受代次保护 |
| 墨迹文件 | PNG 及 meta 通过同目录临时文件和 replace 发布，完成标记最后写入；缓存复用和正式时间轴校验均检查版本、帧数、画布及 PNG 完整性；截断帧被拒绝，准备预览时可重建 |
| 多字操作 | 保留单字入口，新增多字选择、Shift 连续选择与合并添加；复用 OCR 原始 token ID 和真实四边形，选中多字按词目标处理，不推测字框 |
| 邻词与触屏 | 正式文字笔迹构建接入同行邻词距离，限制手写圈横向外扩；框选模式禁用浏览器触摸滚动，避免 pointercancel 丢失选区 |

## 兼容与数据边界

- Web 路径和任务/请求/响应模型保持现有契约；取消复用既有项目授权检查。
- `annotation_ink_v4_neighbor_bounds` 进入构建输入摘要。旧勾画确认不会被静默当作新几何使用，需要重新准备同步预览并确认；原图片、音频、人工条目和历史成品保留。
- 草稿暂存属于当前浏览器会话内存，关闭/刷新前会提示未保存内容；这不等于跨浏览器重启的持久草稿存储。
- 取消是安全边界上的协作取消，正在等待的上游 HTTP 请求可能需要先结束；取消后的建议不发布。
- 邻词约束针对同行的横向外扩，不声明已经完成跨行、旋转字、极小字间距下的独立像素精度验收。

## 验证

- 勾画 Python 原有专项：261 passed、1 skipped；新增稳定性回归：8 passed。
- 新增覆盖：OCR 限流恢复/耗尽/不可重试/退避取消；AI 零结果与取消发布；损坏帧检测与重建；原子替换失败保留旧 PNG；正式文字路径的邻词边界。
- 前端覆盖：未发送删除撤销、在途删除补偿、保存期间编辑叠加、同目标新增 ID 不混淆、多字选择、未关联草稿切页恢复、轮询断网恢复和取消终态、旧轮询迟到响应。
- 11 个 JS 套件通过；修改 Python 文件 Ruff/编译、Agent 能力矩阵检查通过。新增任务进度套件与既有保存/恢复套件已登记到 `scripts/run_checks.py`。
- Edge 隔离浏览器回归通过真实多字控件、合并添加、任务已用时、取消按钮及终态隐藏；API 为测试桩，无真实用户项目写入。
- 全量 `pytest checks -q`：**1625 passed、1 skipped、1 failed**（210.59 秒）。唯一失败为原有 `test_detect_elements_is_pixel_deterministic_across_fresh_dirs`，`case_02_gap_4` 的两次检测摘要不一致；该 Mask 算法和测试本轮未修改，不能据此宣布全仓全绿。
- 仓库 Ruff 仍有 16 处既有问题，位于本轮未修改文件。quick 入口因此仍无法完整通过。
