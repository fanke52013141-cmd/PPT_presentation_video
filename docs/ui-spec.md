# PPT Studio UI 规范（工作区 shell + 分镜规划）

> 本规范由「分镜规划（AI 自动模式）」参考稿固化而来。顶部、左侧步骤栏与
> 第 1–6 步的右侧标题栏以本页「工作区四区统一规范」为准；正文卡片和其余
> 交互沿用下文规则。参考文件为用户提供的分镜规划 HTML。
>
> 配套实现层：`static/stitch.css` 末尾的
> `Storyboard workspace UI spec layer`；交互逻辑见 `static/storyboard.js`。

## 工作区四区统一规范（可见步骤 1–6）

| 区域 | 固定规格 | 适用范围 |
| --- | --- | --- |
| 左侧顶部状态图例 | 白底，底部分隔线；11px/500 文本；已完成绿 `#10b981`、进行中橙 `#ee5d36`、待完成灰 `#cbd5e1` | 八步共用 |
| 左侧菜单栏 | 宽 256px；每项高 40px、圆角 12px、间距 6px；20px 数字徽标；三态分别呈现对勾、静态橙点、灰点 | 八步位置固定，第 7 步禁用时仍占位 |
| 顶部标题栏 | 高 56px、水平内边距 20px；Logo、当前项目、操作区共用同一栏 | 工作区所有步骤 |
| 右侧步骤标题栏 | 通栏白底，最小高 59px（上下各 14px + 30px 控件 + 1px 底线），左右内边距 32px；标题 18px/700，前置 6×20px 橙竖条；按钮高 30px、字 12px、圆角 8px、同组间距 8px | 可见步骤 1–6，依次对应内部面板 `1/2/3/5/6/10` |

所有项目的八个步骤共用同一个工作区边界：右侧标题栏的背景及底线从左侧
步骤栏右边缘一直延伸至工作区右边缘。32px 只作为标题文字和正文内容的
内边距，不得再加在工作区外层形成侧栏与标题栏之间的空白。

这四区使用参考稿的 `#ee5d36` 橙色与 `#fff5f0` 激活底色，由
`static/stitch.css` 末尾的 `Shared workspace chrome` 规则统一设置。标题栏只
保留一行；工具较多的 AI Mask 页面在工具组内部横向滚动。分镜规划标题栏吸顶，
其页签行独立跟随正文滚动。第 1–6 步的标题、按钮、位置与状态样式不得各自
另设尺寸。窄屏时标题栏保持单行，工具组横向滚动。

## 第 1 步正文参考范围

用户提供的「准备文章」HTML 只用于「导入文章 / 输入话题」切换栏下方的
正文区域。导入模式是一张占满右侧内容宽度的白色编辑卡片，正文从卡片内
24px 处开始，保留 Markdown 可编辑性。话题模式在同一张卡片内依次放置
单行话题输入、AI 生成按钮、「文章内容」标题和全文预览；预览宽度随卡片
铺开，长文由该视图纵向滚动。现有保存、复制和文章生成操作继续可用。
左侧步骤栏、全局顶部栏与「准备文章」标题行不从这份参考稿取样。

## 2. 左侧步骤菜单栏（8 步工作区导航）

结构（自上而下）：状态图例 → 8 个步骤项（纵向滚动）→ 底部 CTA。

- 容器：宽 256px，白底，右侧 1px `#e2e8f0`（80%）描边。
- 状态图例：顶部一行，11~12px/slate-500/500。三态示例点：已完成
  `#10b981`（带 `#d1fae5` 双环）、进行中 `#f46a38`（带 `#ffedd5` 双环）、
  待完成 `#cbd5e1`。图例下缘 1px `#f1f5f9` 分隔。
- 步骤项（通用）：高 40px（上下 padding 10px + 内容 20px），左右 padding
  12px，圆角 12px，项间距 6px；左侧 20px 圆形数字徽标 + 14px 步骤名。

三态样式：

| 状态 | 数字徽标 | 右侧指示 | 底色/描边 | hover |
| --- | --- | --- | --- | --- |
| 已完成 | `#ecfdf5` 底 / `#10b981` 字 / 1px `#10b981`30% 描边 | 16px 圆形 `#10b981`10% 底 + 白色对勾（12px） | 透明 | `#ecfdf5`40% 底 + `#d1fae5` 描边 + 右移 4px |
| 进行中 | `#f46a38` 底 / 白字 | 10px 静态橙点 | `#fff0ea` 底 + 1px `#f46a38`25% 描边 + 微阴影 | 无（`cursor: default`） |
| 待完成 | `#f1f5f9` 底 / `#94a3b8` 字 | 6px 圆点 `#cbd5e1` | 透明，文字 slate-400 | `#f1f5f9`80% 底、文字转 slate-700、右移 4px |

- 步骤项动效：`transition: all .2s`；hover 右移 4px（`translateX(4px)`）；
  数字徽标 hover `scale(1.05)`。
- **进行中步骤项带流光（sheen）**：元素 `overflow:hidden`，`::after` 为
  宽 50% 的白色渐变高光条，3.5s 无限循环（0% 在 `-100%`，40%~100% 掠过
  至 `200%`）。
- 可选步骤（数字人）禁用时保留菜单位与序号，仅不可进入，不参与进度。
- 底部 CTA「一键生成视频」：
  - 高 44px（h-11），通栏宽，圆角 12px，白字 14px/500。
  - 底色 `linear-gradient(90deg, #f97316, #f46a38, #f59e0b)`，
    `background-size: 200% auto`，3s `gradientFlow` 无限流动。
  - 阴影 `--spec-shadow-glow`；hover 上浮 2px、阴影增强；active
    `scale(0.98)` 归位。星形图标 hover `rotate(12deg) scale(1.1)`，300ms。
  - **按钮容器上方不放任何分隔线/边缘线**（参考稿的 `border-t` 已按
    需求去除），仅保留 16px 内边距的白色容器。

## 3. 「返回首页」按钮

出现在工作区顶栏右侧（及未来任何需要返回首页的位置），统一样式：

- 高 30px，padding 0 12px，圆角 8px；12px/500/slate-600；1px `#e2e8f0`
  描边，白底。
- Hover：`#f8fafc` 底、文字 slate-900、描边 `#cbd5e1`、轻阴影；

- 左侧房屋线形图标 14px/slate-400，hover 时图标转 slate-600 并左移 2px。

## 4. 步骤顶部标题栏（8 个步骤通用）

每个步骤面板顶部为一条「标题 + 工具按钮」的子标题栏：

- 容器：**通栏**（左右贯穿工作区，不留面板内边距）白色 85% 半透明 +
  `backdrop-blur(10px)`，底部 1px `#e2e8f0`（80%）细线，左右 padding
  32px、上下 14px（py-3.5）；sticky 吸顶；分镜规划的页签行不吸顶、跟随
  内容滚动。
- 标题：左侧 6×20px 品牌橙圆角竖条（2s `pulse` 呼吸）+ 18px/700/
  slate-900 标题文字，间距 10px。
- **按钮规格**（全部步骤共用）：
  - 高度 30px（`py-1.5` + 12px 文本行高）；主 CTA 同高但左右 padding
    16px（`px-4`）。
  - 字号 12px；次级按钮字重 500，主 CTA 字重 600。
  - 圆角 8px；图标 14px，与文字间距 4px。
- **按钮排布**（2026-10-06 最新用户裁决，全部 8 个步骤通用）：
  工具按钮从最右侧的进入下一步按钮向左连续排列，统一间距 8px，
  不在 Prompt 与动作组之间使用弹性空白。Prompt 按钮位于操作组左侧，
  AI 标注参数紧邻橡皮左侧。两组之间为 1px×16px `#e2e8f0` 竖分隔线，
  左右各 2px；标题栏底部保留 1px `#e2e8f0` 横线。
- 所有「进入」按钮统一参考「进入勾画标注」：深色 `#17191d` 底、白字，
  hover `#2c2e33`。其余工具按钮白底、深色文字、1px `#e2e8f0` 描边。
  导航按钮仅保留一个统一的向右箭头，不同时使用 SVG 和伪元素箭头。
- 不显示「本项目不加勾画」按钮，保留视频中启用勾画开关；
  不显示数字人顶部的可选步骤说明，也不展示重复按钮含义的静态提示。
- **按钮动效**：统一 `transition: all .2s`；按下 `active:scale(.95)`；
  危险按钮（批量删除）hover 转 `#fef2f2`60% 底 / 红字 / 红描边，激活态
  红底白字。图标微动效：刷新图标 hover 旋转 180°（500ms）、闪电图标
  hover `scale(1.25)`（300ms）、加号 hover 旋转 90°（300ms）。
- 禁用态：`opacity:.5` + `cursor:not-allowed`，去掉 hover 位移与阴影。

## 5. 二级菜单（分页 Tab）

步骤内存在多页内容时（分镜规划的「第 N 页」、后续步骤的页签），使用统一
Tab 条：位于标题栏下方，横向滚动、隐藏滚动条，Tab 间水平间距 10px，
容器上下 padding 8px/4px。

- 激活页：品牌橙底、白字、12px/700、圆角 8px、`px-3 py-1.5`、轻阴影；
  左侧拖拽手柄字符 `⠿` 用 60% 白。
- 默认页：`#f8fafc` 底、1px `#e2e8f0`80% 描边、slate-600 文字、12px/500；
  hover 白底、文字 slate-900、描边 `#cbd5e1`；手柄 `⠿` 用 slate-400。
- 「添加幻灯片」：虚线（dashed）`#cbd5e1` 描边的幽灵按钮，hover 品牌
  橙字 + `#fff7ed`60% 底 + 橙描边 40%，加号图标 hover 旋转 90°。
- 批量删除徽标：16px 红色（`#ef4444`）圆形 `✕`，绝对定位于 Tab 右上角
  （-6px/-6px），默认隐藏、hover 或批量模式中显示，hover 加深 `#dc2626`。
- 拖拽排序：拖动中 `opacity:.45 + scale(.96) rotate(-2°)`；目标位
  `#f46a38` 描边 + `0 0 0 2px rgba(244,106,56,.35)` 光环。
- 切页 200ms 过渡；删除按 `scale(.75)+淡出` 200ms 退场后重排序号。

## 6. 内容区域（自适应高度卡片）

标题栏与二级菜单以下为内容区。**工作区骨架**遵循：页面为 `#f8fafc`
浅灰画布，各步骤面板不再是"白色圆角大容器"（屋顶）包裹一切，内容以
白色浮动卡片直接落在浅灰底上；内容列最大宽度 1280px 居中，与页面边缘
保持 32px（`px-8`）内边距，卡片纵向间距 12px。

- 外层卡片：白底、圆角 16px、1px `#e2e8f0`90% 描边、`--spec-shadow-card`
  静态阴影；hover 升为 `--spec-shadow-float`（300ms，仅阴影过渡）。
  **卡片高度随内容自适应，不设固定高度，不出现内部滚动。**
- **分镜规划页一次只显示一页**：上方"第 N 页"Tab 切换当前页，卡片内为
  当前页的完整内容（参考稿结构）。
- 卡片内按阶段分节，节间 1px `#f1f5f9` 分隔线（divide-y）：
  - 「第一步：演讲稿」：白底，padding 24px；
  - 「第二步：画面与演讲片段」：`#f8fafc`40% 底，padding 24px。
- 分节标题：24px 圆角（8px）数字徽标（第一步橙 `#ffedd5` 底橙字、第二
  步蓝 `#eff6ff` 底蓝字，均带同色 2px 外环）+ 14px/700/slate-900 标题，
  标题行底部 1px 分隔线。
- 表单字段：
  - 字段标签 12px/600/slate-500、大写间距（letter-spacing .05em）；
    右侧可挂弱说明（11px/slate-400，如「共 N 字」）。
  - 输入框/文本域：`#f8fafc`70% 底、1px `#e2e8f0` 描边；大字段圆角 12px、
    内边距 14px（主标题/演讲稿），小字段圆角 8px、内边距 12px（片段）。
  - 焦点：白底 + 品牌橙描边 + `0 0 0 2px rgba(244,106,56,.2)` 光环，
    200ms 过渡。
- **自适应高度文本域**：`resize:none`，高度由内容撑开（`field-sizing:
  content`，配合 JS `autoGrow`：`height:auto → scrollHeight`）；最小高度：
  主演讲稿 90px、片段字段 76px、画面元素等长文本 110px。
- 双列等高：画面列与演讲片段列用 `grid-cols-2`、列距 24px、
  `items-stretch`，两列高度始终等于较高一列（`syncRowHeights` 重算）。
- 子卡片（每个可视化片段）：白底、圆角 12px、1px `#e2e8f0`90% 描边、
  padding 16px、纵向间距 12px；hover 描边 `#f46a38`40% + 阴影加深，200ms。
  左上 20px 深色（`#0f172a`）圆形序号，hover 转品牌橙。
- 状态提示（如「演讲稿已修改，需重新生成可视化」）：12px 弱化文本卡片，
  不打断编辑。

## 7. 动效规范汇总

| 名称 | 参数 | 用途 |
| --- | --- | --- |
| 按钮基础过渡 | `transition: all .2s` | 全部按钮/hover/焦点 |
| 按压反馈 | `active:scale(.95)`（CTA `.98`） | 全部按钮 |
| fade-in-up | `.35s cubic-bezier(.16,1,.3,1)`，opacity 0→1 + translateY 8px→0 | 卡片/Tab 进场（一次性） |
| sheen 流光 | 3.5s 循环，白色高光条掠过 | 进行中步骤项 |
| pulse 呼吸 | 2s 循环，opacity 1→.5 | 标题橙竖条 |
| gradientFlow | 3s 循环，背景位 0%→100%→0% | 底部 CTA 渐变流动 |
| 图标微动效 | hover 时旋转/缩放/位移，200~500ms | 见第 4 节 |

可访问性：`@media (prefers-reduced-motion: reduce)` 下全部动画/过渡降至
`0.01ms`，滚动改为瞬时。

## 8. 分镜规划两段式交互逻辑（本规范的行为部分）

自动模式下，Step 2 顶栏固定呈现「生成演讲稿」与「内容可视化」两个动作
按钮 + 右侧主 CTA「进入图片生成」：

1. 点击「生成演讲稿」（无稿时；已有稿则显示「查看/编辑演讲稿」）→
   （可选填写补充要求）→ 逐页生成标题与演讲稿。**生成期间「内容可视化」
   必须处于禁用态（可见但不可点）。**
2. 每一页演讲稿全部生成完毕后，「内容可视化」自动恢复可点；未生成过
   演讲稿时它保持禁用，不展示任何禁用原因文字（2026-10-06 起）。
3. 演讲稿发生修改后，既有可视化标记为过期：按钮文案转「重新生成可视
   化」，「进入图片生成」同步禁用，直至重新执行内容可视化。
4. 点击「内容可视化」→ 生成第二步「画面文字/画面元素 + 对应演讲片段」
   映射，渲染进内容卡片；生成期间按钮禁用。
5. 手动分镜模式不显示这两个按钮，改用「添加幻灯片/批量导入」。

## 9. 落地与验收

### 交互可达性与状态反馈（2026-10-05）

- 八步主导航支持 Tab、Enter/Space、方向键和 Home/End；当前步骤使用
  `aria-current="step"`，没有对应面板的可选步骤保留序号并标记不可进入。
- 分镜页签支持键盘激活与 Alt+左右方向键排序；排序复用现有保存与失效规则。
- 正常校验在字段旁或当前步骤/弹窗内呈现，不进入全局 Toast；字段错误关联
  `aria-invalid` 和实际存在的 `aria-describedby` 元素，修正后清除。
- 禁用控件只呈现禁用态本身，不在工具栏生成「禁用原因」提示文字（如
  「还缺少 N 张图片」「当前没有可删除的图片」）；操作被拒时的错误仍走
  既有 Toast/字段错误通道。
- **状态贴对象（2026-10-06 用户裁决）**：图片与旁白的生成状态只呈现在
  对应卡片上——图片卡片右上角与旁白页标题行右侧均为三态 chip
  （待生成=灰 / 生成中=橙+spinner / 完成·已生成=绿+对勾），差异原因只
  保留在悬浮 `title`；页面顶部不放全局加载条、进度长文案或状态汇总。
- **错误才浮层**：成功反馈不弹 Toast、不播报，卡片状态变化即反馈；仅
  真实失败走全局 Toast（error-only 策略，`checks/test_toast_policy.js`）。
- **弹窗单滚动**：任何弹窗同屏只允许一条滚动条（内容区为唯一滚动层，
  遮罩与面板本体不得再出滚动条）。
- 弹窗统一管理顶层焦点、Tab 循环、背景 inert、Escape 与关闭后焦点恢复。
  Escape 必须调用原有关闭行为；危险确认默认焦点在取消按钮。
- 图片步骤区分加载、缺少分镜、图片槽位与加载失败；缺少分镜提供返回第 2 步，
  请求失败提供重新加载，不以永久留白代替状态。
- 长任务说明可切换步骤返回查看，但必须保持本地服务运行。请求停止表示
  等待当前请求或阶段安全结束后停止；批量图片仅停止后续页面排队。
- 任务控制和状态提示复用现有工作区按钮、字体与品牌变量，不改动已合规的
  30px 控件或恢复旧版全局视觉风格。

- 样式实现集中在 `static/stitch.css` 末尾 `Storyboard workspace UI spec
  layer`；新增界面一律复用该层类名/选择器，不另起色值。
- 验收口径：八步工作区（含可选数字人步骤）逐页检查——Logo、侧边栏
  三态、底部 CTA、返回首页、顶部标题栏按钮高度/间距/动效、二级 Tab、
  自适应卡片；分镜规划页按第 8 节走完两段式流程。
- 本规范与 `docs/ui_style_reference.md`（Stitch 层说明）冲突时，以本文
  为准；首页/课程库等非工作区界面仍遵循 Stitch 层。


## 任务与加载状态

实际页面沿用 [加载状态设计](loading-states/DESIGN.md)。状态呈现在所影响的
页面或任务旁：分镜两个生成阶段分别显示；图片和音频逐页显示；AI 标注与
勾画推荐在各自工作区显示；数字人显示真实任务状态；MP4/PPTX 分别呈现
排队和执行状态。首次读取使用骨架，占位不覆盖已有编辑内容。
动态横条仅用于实际执行，排队不播放执行动画。状态轮询断网显示「状态连接
中断，正在重试」，继续原有轮询，不将网络错误认定为生成失败。
完成态由实际产物与确认状态决定，原始失败信息仍可通过既有错误区域查看。

## 八步工作区标题栏按钮规范（统一执行）

| 项目 | 规格 |
| --- | --- |
| 高度与字号 | 高 30px，字号 12px，字重 600，垂直居中 |
| 内边距与圆角 | 水平 12px，圆角 8px；宽度随文字，不挤压文字 |
| 排列 | 同组间距 8px；Prompt 在工具组最左，进入下一步在最右 |
| 默认按钮 | 白底，1px `#e2e8f0` 描边，文字 `#1d1d1f` |
| 进入按钮 | 统一暗底 `#17191d`、白字；沿用进入勾画标注规格，箭头只保留一个 |
| 分隔线 | 1×16px，`#e2e8f0`，左右各 2px 外边距，垂直居中 |
| 生图 Prompt | 必须紧接右侧分隔线：`生图 Prompt → 竖线 → 其他工具 → 进入 AI 标注`；左侧不放分隔线 |
| 动态工具 | 插入、刷新、切换项目后仍保持上述顺序；排序逻辑必须把分隔线作为 Prompt 后的固定节点 |
| 状态 | 标签保持静态；生成动效呈现在内容区域，按钮禁用时不改变尺寸 |

以上工作区规格优先于旧的按钮样式段落，适用于八个可见步骤。


### 视频预览与手写圈

标注预览使用视口居中的原生 dialog，距视口四边至少 16px，内容超出时在弹窗内滚动。视频预览使用深色画布、底部播放/进度控件，统一提供倍速、100–200% 音量增强、全屏、画中画及下载。标注预览下载导出真实 MP4，保留声音、字幕和勾画；最终作品直接下载已有 MP4。画中画按浏览器能力采用视频或页面画中画。

作品输出的最新视频按窗口剩余高度等比例缩放，为播放器工具、下载、删除和生成调速 MP4 的操作行及卡片底部留出空间。总耗时与“最新渲染”同行，正常作品不显示底层 Mask 技术标签。播放器倍速、音量与输出语速使用原生下拉菜单，展开选项不得带动内容滚动；全屏时重新按全屏空间计算尺寸。

手写圈使用包住目标文字的椭圆中心线，附加确定性的轻微不规则曲线、压力变化和墨迹纹理，禁止将圆弧逐点推到矩形边界。修改生成几何时更新墨迹版本，使旧预览重新编译。


### 勾画标注首次使用流程

设计依据见 `docs/annotation-workspace/DESIGN.md`（Stitch Design Taste）。工作区采用“AI 自动勾画 → 检查画面与语音 → 确认本页”的流程线；左侧为画面，右侧为结果与确认。空页突出 AI 勾画，有结果时突出同步预览，重新生成降为白色次要操作。讲稿关联、逐字候选和手动绘制工具直接呈现，不使用下拉或折叠入口。正常几何状态不重复显示，异常范围与起笔时间保留用户可理解的提示。进行中的阶段在结果区显示，提交按钮禁止重复发起任务。确认仍基于真实保存状态，禁用条目不计入确认数量。
