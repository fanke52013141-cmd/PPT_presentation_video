# 固定视觉参考图

本目录中的图片是图片生成阶段使用的风格参考图。

## 内置教学风格

- `PPT模板.png` 与 `PPT示例.png`：手绘讲解风。
- `government_brief/`：政务教学风。
- `light_teaching/`：轻松教学风。
- `blackboard_chalk/`：黑板粉笔风。
- `annotated_notes/`：三色批注笔记风。
- `textbook_diagram/`：教材图解风。
- `minimal_classroom/`：简约课堂信息图。

每个目录的 `reference_*.png` 会随对应的内置风格作为生产参考图提交。风格板只用于界面预览，不会替代生产参考图。

## 固定生产合同

- 每页生成一张完整的 1920×1080 位图，四周外边框为纯白色 `#FFFFFF`。
- 标题区、正文安全区和底部字幕区由服务端固定；风格提示词不能覆盖这些边界。
- 底部字幕区始终保留纯白，生成结果会再经过像素校验与清理。
- 标题、正文、图标、箭头、连线和总结由图片生成模型绘制；Remotion 只显示页面与由 Mask 生成的 PNG reveal 图层。
- 最终视频背景色由项目设置决定，默认 `#FEFDF9`。

更新内置参考图时，必须同步检查相应 YAML 风格指引与图片生成结果。
