先看最常用的一种：AI 大模型里的 token。
它是模型处理文本的最小单位，并不是简单等于一个汉字或者一个字母。

slide_003 4 条旁白
具体怎么换算呢？
中文里大约一个 token 对应 0.75 个汉字，一千个 token 大概是七百五十个汉字。
英文里一个 token 约等于 0.75 个单词，长词还会被拆成小段。
标点、空格和换行也都会占用 token。

模型不会直接读“字”，而是把文字切成一小段一小段的 token，再基于这些片段去计算、理解和生成内容。

那 token 有什么实际用处？
首先是计费，调用 API 通常按输入加输出的 token 数量收费。
其次是上下文窗口，模型有最大 token 上限，决定了它最多能记住多少对话内容，超过就会遗忘前面的信息。
