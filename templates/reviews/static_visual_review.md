# 静态视觉审核清单

审核对象：

- `visual_draft.png`
- `slide_spec.json`
- `narration.txt`

输出：`visual_review.yaml`

检查项：

- 这页是否一眼能看懂核心概念？
- 构图是否符合当前项目的图片风格设定？（以项目配置为准，不默认某一种风格）
- 画面是否为真实文字预留空间？
- 配图是否服务理解，而不是纯装饰？
- 是否适合后续拆成可动画元素？
- 字幕区是否保持为空，未生成任何内容？
- 是否出现乱码文字、假文字、错误图表？

状态：

- `approved`: 通过。
- `revise`: 方向可用，但需要修改 → 回到图片生成或图片风格调整阶段。
- `rejected`: 方向错误，需要回到分镜或风格阶段。

对 `revise` 项，请额外记录需要修改的具体对象（如某张配图、某个文字区），便于精准回流。
