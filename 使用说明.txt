PPT 视频工作台 便携版 - 使用说明
====================================

【新电脑上的操作（共一步）】
1. 把整个文件夹解压到任意位置（建议路径不要太深，例如 D:\PPT工作台）
2. 双击「启动.bat」
3. 浏览器会在几秒后自动打开 http://127.0.0.1:8000

就这些。不需要安装 Python、Node.js、ffmpeg，也不需要任何命令行操作。
所有配置（模型连接、API 凭据、项目库、历史项目）都已在包内，与原电脑完全一致。

【停止服务】
关闭启动时的黑色窗口，或双击「停止.bat」。

【常见提示】
- 首次双击 启动.bat 若弹出 Windows SmartScreen（"已保护你的电脑"），
  点击「更多信息」→「仍要运行」即可，仅第一次会提示。
- 若提示 8000 端口被占用：用记事本打开 启动.bat，
  把 PPT_STUDIO_PORT=8000 改成其他数字（如 8010）后保存，重新启动。
- 字幕字体：本包设计使用 LXGW Marker Gothic 字体。如该字体未安装，
  渲染时字幕会自动回退为微软雅黑（与原电脑未装字体时的行为一致，不影响使用）。

【数据与安全】
- 全部业务数据在 data\ 文件夹（含数据库与 API 凭据 credentials.json），
  历史项目在 runs\ 文件夹。请妥善保管整个文件夹，不要外传。
- 渲染视频产物在各项目的 runs\<项目>\outputs\ 下。

【本包内置】
- 便携版 Python 3.13（runtime\python）
- 便携版 Node.js 22（runtime\node）
- 完整版 ffmpeg 7.1.1（tools\ffmpeg\bin，启动时强制优先使用）
- Remotion 渲染引擎及 Chrome 渲染内核（scripts\remotion\node_modules）
